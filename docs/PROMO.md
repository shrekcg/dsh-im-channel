### 🚀 dsh-lark-bridge — 把 DeepSeek Harness 接进飞书

一个开箱即用的**飞书/Lark 双向 AI 通道**，让你的 DSH 助手"长"在飞书里：

**✨ 核心能力**
- 💬 **持久对话**：跨消息记忆、话题隔离、群聊/私聊
- ⌨️ **真流式输出**：边生成边显示，平滑打字机 + 底部耗时
- 🛠️ **40 个飞书 MCP 工具**：文档/表格/日历/任务/邮件/云盘，一句话操作
- ⌨️ **斜杠命令**：`/new` `/compact` `/model` `/status`，飞书内即时执行
- 📊 **IM 机器人设置页**：DSH 插件设置里新增 tab，实时看渠道状态
- 🧩 **可插拔**：`dsh plugin add dsh-feishu-channel` 一键安装，不侵入核心

**📦 安装**
```bash
npm install -g dsh-feishu-channel   # 或 dsh plugin add dsh-feishu-channel
npm run setup    # 初始化向导
npm run doctor   # 诊断
```

## English Version

### 🚀 dsh-lark-bridge — Feishu/Lark channel for DeepSeek Harness

A ready-to-use **bidirectional Feishu/Lark AI channel** that puts your DSH assistant inside Feishu:

**✨ Highlights**
- 💬 Persistent conversations: cross-message memory, topic isolation, group & DM
- ⌨️ True streaming output with smooth typewriter + elapsed footer
- 🛠️ 40 MCP Feishu tools: docs/sheets/calendar/tasks/mail/drive in one sentence
- ⌨️ Slash commands: `/new` `/compact` `/model` `/status` right in Feishu chat
- 📊 IM-bot status tab inside DSH plugin settings
- 🧩 Pluggable: `dsh plugin add dsh-feishu-channel`, no core changes

**📦 Install**
```bash
npm install -g dsh-feishu-channel   # or: dsh plugin add dsh-feishu-channel
npm run setup    # setup wizard
npm run doctor   # diagnostics
```
